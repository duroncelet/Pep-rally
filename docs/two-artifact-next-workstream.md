# Buyer outcome model — next workstream, not built this round

Kelly's November 11 outcome decision: a finished Rally should give the buyer a personal live mini-site for the occasion and a designed PDF packet as a permanent record. The buyer pays for the completed outcome. Markdown and spreadsheet exports are secondary. The live page should last roughly 12 months with an explicit expiry; the downloaded packet remains the buyer's copy. Existing code does not yet implement this contract.

Existing implementation offers browser-printable results, portable HTML and immutable URL-fragment snapshots. It does not provide server-rendered downloadable PDF files or a revocable, account-owned shared mini-site. The distinction matters for buyer privacy and for sharing with nontechnical recipients.

Suggested next milestone: free Originals first, using the same validated result model for both outputs. Each Rally also needs a finished sample that a visitor can open and then personalize, with the blank form directly available. Hosted pages require owner-scoped storage, unguessable share tokens, explicit share consent, revoke/delete, privacy-safe defaults, update semantics, expiry and abuse limits. PDF delivery needs a renderer, fonts/assets, multipage layout tests and a download endpoint with the same access policy. Do not publish guest contacts or private contribution preferences by default.

Rough engineering estimate (not a commitment): 1 day to settle sharing/privacy and output contracts; 2–3 days for storage/access/share/revoke; 1–2 days for PDF rendering and layouts; 1–2 days for cross-device, accessibility and adversarial tests. Total 5–8 engineering days for the two free Originals, assuming existing authentication/storage work and no new collaboration or paid-AI features. Each additional template needs separate outcome validation; do not advertise every catalog concept as complete.

Acceptance: buyer opens a finished sample, replaces it with their own details, and creates a real plan; downloadable designed PDF matches it; live page opens signed out without exposing private fields; owner can revoke it; exports survive long text and mobile layouts. Review costs and retention before production. The new Festival Planner is a separate Rally build, not an audit fix; do not promise stage conflicts before set times exist. Requires a separately approved build/deployment workstream.
